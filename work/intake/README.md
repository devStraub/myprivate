# Intake de aprendizados

Área transitória somente para propostas que já chegaram abstratas e sanitizadas. Nenhum conteúdo bruto corporativo pode entrar aqui.

## Regras

- use [`../../templates/work-learning.md`](../../templates/work-learning.md);
- mantenha `status: draft` e `sanitization.approved: false` até revisão;
- em captura portátil, use `capture_id` único, `captured_at` e `review_state: pending`;
- não altere ou apague capturas anteriores no dispositivo externo; correções são novos arquivos relacionados;
- rejeite propostas que ainda permitam reidentificação;
- após aprovação, incorpore na fonte canônica e preserve a decisão conforme o processo definido pelo proprietário;
- intake não conta como evidência de competência nem conhecimento validado.

Uma proposta pode indicar uma lacuna de estudo, mas só deve apontar para scouting/backlog após generalização, sanitização e aprovação. O item de estudo não herda detalhes do caso profissional.

Não existe prazo para esvaziar o intake. A revisão ocorre sob demanda e pode consolidar somente parte das pendências.

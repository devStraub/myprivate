# Integrações com agentes

Adaptadores opcionais para tornar as regras da Toolbox reconhecíveis por diferentes agentes e IDEs.
Eles não substituem os documentos canônicos e não devem ser copiados para um projeto sem autorização.

- [`copilot/`](copilot/README.md): instruções e prompts reutilizáveis para GitHub Copilot.

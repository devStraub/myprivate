# Cases

Experiências reais sanitizadas que preservam investigação, evidências, decisões e lições sem permitir reconstruir empresa ou sistema de origem.

## Índice

Nenhum case foi incorporado na v0.1.

Use [`../templates/case.md`](../templates/case.md) e aplique obrigatoriamente [`../governance/sanitization.md`](../governance/sanitization.md). Em dúvida, rejeite o registro. Cases não substituem knowledge ou patterns; eles fornecem experiência e evidência relacionada.

Quando um case revelar uma lacuna, ele pode propor um tema generalizado para [`../study/scouting/`](../study/scouting/README.md) ou [`../study/backlog/`](../study/backlog/README.md). A proposta não implica que o tema foi estudado.

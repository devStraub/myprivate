# fipas-herbs

Port de coleta silvestre para RSG Core inspirado no `VORPCORE/vorp_herbs` (GPL-2.0).

- 27 especies/modelos naturais.
- Recompensa especifica por planta.
- Animacao, cooldown por no e capacidade de inventario.
- Modelo, distancia, tempo e sessao validados no servidor.
- 29 ingredientes registrados dinamicamente.
- Locales em portugues e ingles.

Os grandes pomares fixos da referencia VORP nao foram ativados nesta etapa; serao tratados como agricultura planejada.

# fipas-lumberjack

Port de coleta de madeira para RSG Core inspirado no projeto GPL-2.0 `VORPCORE/vorp_lumberjack`.

- Interacao com arvores via `ox_target`.
- Machado, teste de habilidade, animacao e chance de quebra.
- Cooldown e recompensas validados no servidor.
- Materiais registrados dinamicamente no RSG Core.
- Locale em portugues e ingles.

Conceito e lista de modelos derivados do VORP Lumberjack. Consulte `LICENSE`.

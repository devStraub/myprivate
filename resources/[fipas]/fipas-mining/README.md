# fipas-mining

Port de mineração para RSG Core inspirado no projeto GPL-2.0 `VORPCORE/vorp_mining`.

## Funcionalidades

- Interação com rochas por `ox_target`.
- Picareta obrigatória e chance configurável de quebra.
- Teste de habilidade e animação de mineração.
- Recompensas ponderadas totalmente calculadas no servidor.
- Cooldown individual por rocha.
- Validação de modelo, distância, duração, ferramenta, capacidade e sessão.
- Itens registrados dinamicamente no RSG Core.
- Locale português e inglês.

# Sessões de estudo

Nome sugerido: `YYYY-MM-DD-assunto.md`. Use [`../../templates/study-session.md`](../../templates/study-session.md), registre fontes por ID e mantenha dúvidas abertas explícitas. Sessões são evidência do processo, não prova automática de proficiência.

Uma sessão pode referenciar scouting ou backlog, mas deve registrar o que foi realmente consumido, praticado e validado. Material apenas sugerido continua `not-studied`.

Para captura portátil, use nome derivado do `capture_id`, por exemplo `20260823-184500-transacoes-a7f3.md`, e mantenha `review_state: pending` até a revisão sob demanda.
